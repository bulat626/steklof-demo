# Стеклоф — демонстрация сайта

Посмотреть сайт: **https://bulat626.github.io/steklof-demo/**

Демонстрационный вариант нового оформления сайта «Стеклоф». 58 страниц: услуги, работы, цены, статьи, отзывы, контакты и документы. Есть адаптация для телефонов и ссылка на канал MAX.

## Публикация

Из-за ограничения загрузки через браузер сайт сохранён в нескольких самостоятельных ZIP-архивах `site-part-*.zip`. GitHub Actions распаковывает все архивы в одну папку и публикует её через GitHub Pages. Архивы содержат HTML, CSS, JavaScript, изображения, шрифты и документы; серверная часть не требуется. Для локального просмотра распакуйте все архивы в одну папку.

Форма готовит сообщение WhatsApp. Отправку посетитель подтверждает в самом WhatsApp.

Это демонстрационная копия для согласования оформления, а не официальный новый адрес компании. Добавлен `noindex`, чтобы поисковые системы не индексировали демонстрацию; это не ограничение доступа.

Открытость репозитория не означает предоставления лицензии на использование фирменных материалов, фотографий и содержимого.
